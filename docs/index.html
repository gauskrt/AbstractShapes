AbstractShapes

An attempt to make abstract art with machines.

What it stands for

Seeing the way a painter squints

Painters squint to stop seeing detail and start seeing masses: a pool of light, a dark wedge of hair, a band of green. AbstractShapes makes a machine do the same thing, one shape at a time, without knowing what it's looking at.

Abstraction

An image boiled down to a few hundred flat, overlapping shapes. The first ten capture the composition, the next hundred the figures, and the rest the light. Abstraction here is a matter of degree: you choose how much detail to keep.

The machine as apprentice

The program has no idea what a face, a lotus leaf or a sari is. It only knows how far its canvas is from the target, and it keeps guessing until the gap closes. Whatever looks intentional in the result came from that loop of guessing and checking.

Reproduction

Ravi Varma used a machine, a lithographic press, to bring paintings into ordinary homes. This project feeds one of his paintings back through a machine of a very different kind, as a small homage to that idea.

Why Ravi Varma

A painter who welcomed the machine

Raja Ravi Varma (1848–1906), born in Kilimanoor in present-day Kerala, combined European oil-painting technique with scenes from the Mahabharata, the Ramayana and Kalidasa's Shakuntala. His paintings gave many of India's gods and heroines the faces people still picture today.

In 1894 he set up the Ravi Varma Press in Bombay, later moving it to Malavli near Lonavala. Its colour oleographs sold for a fraction of the price of a painting and hung in homes, shops and shrines across the country. Art that once belonged to palaces became something anyone could own, thanks to a printing machine.

His work is in the public domain, so his paintings can be studied, reused and reinterpreted freely, including by an algorithm.

Ravi Varma's press reproduced paintings faithfully, one colour stone at a time. This program reproduces one roughly, one shape at a time. Both are machines in the service of a picture.
How it works

Guess, check, keep the best

The algorithm is simple: find the one shape that would bring the canvas closest to the painting, draw it, and repeat. The hard part is finding that shape, and for that it combines random guessing with hill climbing.

  1. Start with a flat canvas

    Fill the canvas with the painting's average colour. The error is measured as the root-mean-square difference between every pixel of the canvas and the painting.

  2. Throw darts

    Generate a couple of hundred random shapes (triangles, say) and score each one: how much lower would the error be if it were drawn? Keep the best.

  3. Hill-climb

    Nudge the winner: move a vertex, stretch it, rotate it. If the error drops, keep the change; if not, throw it away. Stop after 100 nudges in a row fail.

  4. Run several climbs, keep the best

    Hill climbing can get stuck on a "good enough" shape, so several independent climbs run in parallel (one per CPU core) and the best result wins.

  5. Draw it and repeat

    The winning shape is painted onto the canvas at 50% opacity and the search starts again for the next one, taking everything already drawn into account.

The colour is calculated, not searched for. For a given shape and opacity α, each covered pixel becomes c′ = (1 − α)·c + α·k, where c is the current pixel and k the shape's colour. The k that best matches the target pixels t has a closed form:
k = meanpixels [ ( t − (1 − α)·c ) / α ]
So the search only explores geometry; for any candidate shape the ideal colour is a single average away.

Error after each shape

Root-mean-square difference from the painting, as a % of full brightness. Big early gains, then a long tail of refinement.

A vocabulary of shapes

Same painting, different alphabets

Change the shape and you change the style. Triangles look faceted, ellipses soft and painterly, curves like loose brushwork. Each of these uses 200 shapes.

Try it yourself

Make your own

AbstractShapes is pure Python and depends only on NumPy and Pillow.

# install
git clone https://github.com/gauskrt/AbstractShapes
cd AbstractShapes
pip install -r requirements.txt

# 200 triangles, saved as PNG and SVG
python -m abstractshapes -i painting.jpg -o art.png -o art.svg -n 200 -v

# soft ellipses on a white background
python -m abstractshapes -i painting.jpg -o art.png -n 300 -m 3 -bg FFFFFF

# an animated GIF of the drawing process
python -m abstractshapes -i painting.jpg -o build.gif -n 150

Modes: 0 combo, 1 triangle, 2 rectangle, 3 ellipse, 4 circle, 5 rotated rectangle, 6 beziers, 7 rotated ellipse, 8 polygon. See the README for every option.
